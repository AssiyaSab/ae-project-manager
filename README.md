# AE Project Manager (ТОО «АзияЭнергоАвтоматика»)

Комплексная цифровая ERP-платформа для управления инжиниринговыми проектами, закупками ТМЦ, продажами оборудования ONKA / WEG, складским учетом, командировками и финансами с гибридным ИИ-шлюзом в Telegram на базе **Gemini API**.

**Организация:** ТОО «АзияЭнергоАвтоматика»  
**БИН:** 150140009432 | **Ставка НДС:** 16%  
**Руководитель:** Директор Быкаев Канат Женисович  

---

## 🏗 Архитектура и стек технологий

- **Frontend:** Next.js 16 (App Router, Turbopack, React 19, TypeScript), CSS Custom Properties (темная инженерная тема).
- **Backend:** Next.js Route Handlers (`/api/*`).
- **База данных:** PostgreSQL на серверлесс-платформе **Neon Database** (`@neondatabase/serverless`) + Prisma ORM v7.
- **ИИ-ядро (AI Layer):** `@google/generative-ai` (Gemini 2.5 Flash / Gemini 3.x Flash) с вызовом инструментов (Function Calling) и компьютерным зрением (Vision).
- **Telegram Bot Webhook:** Серверлесс-шлюз с постоянной клавиатурой, меню команд, инлайн-кнопками прямого согласования и CDN-хранением медиафайлов.
- **Документооборот:** `jspdf` (генерация счетов с факсимиле подписи и печати), `xlsx` (выгрузка реестров для 1С), выгрузка журнала действий в Блокнот (`.txt` с UTF-8 BOM).

## 🚀 Основные модули и возможности

### 1. Гибридный Telegram-шлюз с ИИ-диспетчером (Gemini API)
- **Строгий FSM:** регламентные кнопочные сценарии (двухфакторный ПИН-код при суммах > 500k ₸, кнопки «Принял»/«Не брал» для инструментов, оформление доверенностей Д-1).
- **ИИ-Диспетчер (AI Dispatcher):**
  - **`createFieldAlert`**: при жалобах инженера на аварию или остановку работ автоматически создает алерт со статусом `CRITICAL`/`WARNING`, блокирует задачу и уведомляет ГИПа/Директора.
  - **`createQuickPurchase`**: принимает заявку на материалы в свободной форме (текстом) и отправляет руководству кнопки `[ Одобрить ✅ ]` / `[ Отклонить ❌ ]`.
  - **`parseReceiptOrInvoice`**: извлекает реквизиты (поставщик, БИН, номер, сумма) из фото счета/чека через Gemini Vision.

### 2. Жизненный цикл ТМЦ и автоматические задачи
Цепочка из 8 статусов:
1. `PENDING_APPROVAL` — заявка подана инженером/сборщиком.
2. `IN_PROCUREMENT` — одобрена директором; автосоздание задачи снабжению.
3. `PENDING_PAYMENT_APPROVAL` — снабженец прикрепил счет и сумму.
4. `APPROVED_FOR_PAYMENT` — счет согласован руководством к оплате.
5. `PAID_AND_ORDERED` — **Главный бухгалтер** провел платеж; автосоздание задачи бухгалтерии на доверенность.
6. `POA_ISSUED` — бухгалтер прикрепил скан доверенности формы Д-1.
7. `IN_TRANSIT` — снабженец забрал товар у поставщика («Везем на склад»).
8. `DELIVERED` — кладовщик проверил и принял ТМЦ на склад.

### 3. Модуль продаж оборудования (ONKA / WEG)
- Формирование заказов покупателей со ставкой НДС **16%**.
- Генерация официального PDF-счета на оплату с факсимиле печати и подписи директора.
- Контроль доверенности покупателя (номер, дата, ФИО, скан) перед отгрузкой со склада.

### 4. Учет инструмента с подтверждением в Telegram
- При оформлении выдачи инструмента кладовщиком бот отправляет сотруднику инлайн-кнопки `[ ✅ Принял ]` и `[ ❌ Не брал ]`.
- Статус меняется на `IN_USE` только после персонального подтверждения сотрудником.

### 5. Ролевая модель (RBAC) и безопасность
- **`ADMIN`** — полный доступ ко всем функциям и настройкам.
- **`MANAGER`** — управление проектами, задачами и согласование расходов.
- **`CHIEF_ACCOUNTANT`** — единоличное право утверждения и фиксации оплаты счетов.
- **`ACCOUNTANT`** — выпуск доверенностей Д-1, сверка и подготовка реестров.
- **`SUPPLY`** — прикрепление счетов поставщиков, получение доверенностей, логистика.
- **`WAREHOUSE`** — складской учет инструмента, приемка ТМЦ, отгрузка покупателям.
- **`ENGINEER` / `ASSEMBLER`** — просмотр задач, сдача в ОТК, подача заявок и алертов.
- **ПИН-код верификация:** подтверждение операций > 500 000 ₸ через персональный 4-значный ПИН.
- **Журнал действий (Audit Logs):** экспорт в текстовый файл для Блокнота Windows (`.txt` с сигнатурой UTF-8 BOM `\uFEFF`).

## 🛠 Установка и запуск

```bash
# 1. Клонирование репозитория
git clone https://github.com/AssiyaSab/ae-project-manager.git
cd ae-project-manager

# 2. Установка зависимостей
npm install

# 3. Настройка переменных окружения в .env
DATABASE_URL="postgresql://user:pass@host/db?sslmode=require"
TELEGRAM_BOT_TOKEN="your_bot_token"
GEMINI_API_KEY="your_gemini_api_key"
ADMIN_PASSWORD="your_admin_password"

# 4. Применение схемы Prisma
npx prisma db push
npx prisma generate

# 5. Сборка и запуск
npm run build
npm start
```
